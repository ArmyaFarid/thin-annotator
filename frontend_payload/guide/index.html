ThinAnnotator manual
User manual · English

Annotate thin sections with ThinAnnotator

ThinAnnotator helps you outline mineral grains in polarized-light micrographs. Click a grain and the SAM 2 model proposes its outline. Correct the outline with drawing tools, then record what the mineral is.

Your first grain, in six steps

01

Start the app

ThinAnnotator has two parts. A local service runs the SAM 2 model and reads your image folders. The annotator runs in your web browser. Nothing goes to the internet: images and results stay on your computer.

The launcher window

  1. Open the ThinAnnotator application.The ThinAnnotator Control Panel opens.
  2. Click Start Server.The service starts and loads the SAM 2 model. The first start can take a few minutes.
  3. When the status shows that the server runs, click Open Annotator.Your browser opens http://127.0.0.1:7263.
  4. Keep the Control Panel open while you work.

The same window also builds a training dataset from your finished annotations. See Build a Thin-COCO dataset at the end of chapter 10.

On the first launch, the app asks Choose your language. Click English or Français. You can change the language later in Customize.

Tell the app who is annotating

Use the same username every time

Your username names your files. If you change it, the app does not find your earlier drafts. No password is needed: the profile only records who made each annotation.

To edit the profile later, click your name badge in the top-right corner (Edit annotator profile).

02

Prepare your images

The app reads your images where they already are. It finds the lighting conditions of each image from its file name, so the folder layout and the names must follow one rule.

Folder layout

One field of view (FOV) is one place on the thin section, photographed under several lighting conditions. Put all the images of one FOV in one folder. The parent folder carries the thin-section name. In the app, one FOV folder is one task.

thin-section-01/ thin section name ├── FOV-3/ ← the folder you select · 1 task │ ├── sample01_mod-PPL_comp-na_rot-45.png │ ├── sample01_mod-XPL_comp-na_rot-45.png │ └── sample01_mod-XPL_comp-add_rot-45.png └── notes/ ignored (no matching image)

Accepted formats: .jpg .jpeg .png .tif .tiff .bmp.

File names

Each name follows this pattern:

<prefix>_mod-<MOD>_comp-<COMP>_rot-<deg>.<ext>

TokenValuesShown in the app as
mod modalityPPL plane polarized · XPL cross polarized · RL reflected · FL fluorescence · TR transmittedPPL, XPL…
comp compensatoradd +λ · sous −λ · na no compensatorγ1, γ-1, γ0
rot rotationStage angle in degrees, integer, negative allowed (-45)45°
prefixFree text, at least one character. The app ignores it.—
  • The three tokens _mod-, _comp- and _rot- are required. Their order is free.
  • Extra _key-value tokens are accepted.
  • Keep the same rotation value for all images of one FOV folder.

Layout for a batch

A batch gathers many tasks. Select any root folder. The app searches it at any depth, and every folder that holds correctly named images becomes one task.

campaign-2026/ ← the folder you select └── site-A/ any depth, any names └── thin-section-01/ thin section ├── FOV-3/ 1 task │ ├── sample01_mod-PPL_comp-na_rot-0.png │ └── sample01_mod-XPL_comp-add_rot-0.png └── notes/ ignored

03

Open your work

The home screen asks How would you like to start? and gives three choices. Create a project is marked Coming soon and is not available yet.

Open one task

Use this for a single field of view.

  1. Under Open one task, click Choose a folder.Your system's folder dialog opens.
  2. Select the FOV folder, not the thin-section folder.The editor opens and shows the first image.

Work through a batch

Use a batch for a whole campaign: several thin sections, several fields of view.

  1. Under Create a batch of tasks, click Choose a root folder.
  2. Select the root folder.The app shows Scanning the folder..., then lists the batch under Your batches with its number of tasks.
  3. Click Start (or Resume for a batch you began earlier).The editor opens on the current task of the batch.
ControlWhat it does
NextSaves and exports this task for every lighting variant, marks it as done, and opens the next task that is not annotated.
PreviousGoes back to the previous task in the batch.
already annotatedBadge on a task that was finished earlier.

If the export fails, you stay on the same task, so you lose nothing. When every task is done, the app shows This batch is finished — every task is annotated.

Come back to a task

The browser keeps a copy of your work while you annotate. When you open a task that has work the browser kept but you did not save, the app asks what to do.

  • Draft found: click Restore to continue, or Discard to start from the saved state.
  • If you saved a draft file earlier (Save draft), the app loads it automatically when you open the task. No dialog appears.

    05

    Move around the image

    Micrographs are large. Zoom in close to the grain edges before you correct an outline.

    Zoom and pan

    To do thisDo this
    Zoom around the cursorTurn the mouse wheel.
    Zoom in / out by stepsPress + / −, or use the Zoom in and Zoom out tools.
    PanHold the middle mouse button and drag, or press G for the Pan tool.
    See where you arePress M to show or hide the minimap (bottom left).
    Read pixel coordinatesPress H to show or hide the cursor position. It turns red outside the image.

    Zoom goes from 5 % to 2000 %. Outlines stay sharp at every zoom level.

    The button at the bottom right of the image controls what happens when you switch images. Zoom locked keeps the same zoom and position. Zoom reset fits the new image to the view. Click the button to switch between the two.

    Switch the lighting

    The pills in the tool rail list the lighting variants found in the folder. Click PPL or XPL to change the modality. When the folder has compensator images, the pills γ1 (+λ), γ-1 (−λ) and γ0 (no compensator) appear below. The badges at the top right of the image show the current modality, compensator and rotation.

    Your outlines belong to the field of view, not to one image. They stay in place on every variant, so you can check a grain under crossed polars without redrawing it.

    Undo and redo

    Press Ctrl+Z to undo and Ctrl+⇧+Z (or Ctrl+Y) to redo. On a Mac, use ⌘ instead of Ctrl. The arrows at the top of the tool rail do the same; their tooltip names the step, for example Undo: SAM result.

    • The app keeps the last 50 steps.
    • Switching between PPL and XPL keeps the history. Opening another task clears it.
    • The Refine and SLIC superpixels windows have their own undo while they are open. When you click Apply, the whole session becomes one step.
    06

    Outline a grain

    One object (also called a region) is one mineral grain. You can build an object with any mix of tools: start with the model, then add or cut by hand.

    How objects start

    When no object is selected, your first point, box or shape creates a new object and the panel switches to that object.

    When no object is selected, a click on an existing grain selects that grain instead of drawing.

    While an object is selected, every click goes to the active tool. Click Save in the panel to finish the object before you start the next one.

    Pick a tool to see how it works:

    Click the grain: Add point and Remove point

    These are the SAM tools. You place points; the model finds the grain that contains them. + point means "this is part of the grain". − point means "this is not".

    1. Press S, or click Add point in the tool rail.
    2. Click inside the grain.An outline appears after about one second.
    3. If the outline misses part of the grain, click in the missing part.
    4. If the outline spills onto a neighbour, press X (or click Remove point) and click the part to exclude.The outline updates after each point.

    The panel lists each point under SAM points. Click × next to a point to remove it.

    First click on a new image

    The first click on each image takes longer, often about ten seconds, because the model prepares the image. The next clicks are fast.

    Draw a box around the grain

    A box tells the model where the whole grain is. It often gives the full crystal in one step.

    1. Press B, or click Bounding box in the tool rail.
    2. Drag a box that encloses the grain with a small margin.The outline of the grain appears.
    3. If needed, add S or X points to adjust the result.

    Trace the grain with a polygon

    Use the polygon when the model cannot find the edge, for example on very low-contrast grains.

    1. Press P, or click Polygon lasso in the tool rail.
    2. Click along the edge of the grain to place vertices.
    3. To remove the last vertex, press Backspace.
    4. To close the shape, click the first vertex.The polygon becomes a new object, or a new piece of the selected object.

    To cancel the polygon in progress, press Esc.

    Draw the grain freehand

    1. Press F, or click Freeform draw in the tool rail.
    2. Hold the mouse button and draw around the grain.
    3. Release the button.The app closes the stroke and fills it.

    Freeform is fast for small grains and for patching a gap in a SAM outline. To cut instead of add, switch the panel to Erase first (see Fill and Erase).

    Build the grain from superpixels

    SLIC cuts an area into small patches of similar colour, called superpixels. You keep the patches that belong to the grain. This works well on grains with fuzzy edges.

    1. Press L, or click Superpixels (SLIC) in the tool rail.
    2. Drag a box around the area.The app shows Computing SLIC..., then opens the SLIC superpixels window. All patches start as kept.
    3. Click each patch that does not belong to the grain.The counter at the top shows how many patches you keep.
    4. If an object is selected, choose Add to mask or Remove from mask. With no object selected, the kept patches form a new object.
    5. Click Apply.

    Inside the window, the wheel zooms and the middle button pans. Reset brings back every patch. Cancel closes the window without changes. If the app says SLIC area too large, draw a smaller box.

    Every tool also has a button in the tool rail. With the default Flyout menus layout, the three SAM tools share one button, SAM tools: hover it to pick one. Once you pick a tool, the button shows that tool's icon.
    07

    Fill and Erase

    Polygon lasso and Freeform draw do two jobs. With no object selected, the shape you draw becomes a new object. With an object selected, the Fill / Erase switch in the panel decides what the shape does to that object.

    SwitchThe shape you drawPreview while drawing
    Fillis added to the object. Use it to cover a part the outline missed.Solid amber (polygon) or orange (freeform) line
    Eraseis removed from the object. Use it to trim an edge or cut a hole, for example around an inclusion.Dashed red line

    The switch works on any object, however you made it: SAM points, a box, a polygon, a freeform stroke or superpixels.

    Add a missing part

    1. Select the object: click it on the image or in the panel.
    2. In the panel, click Fill.
    3. Press P or F and draw the missing part. Let the shape overlap the object a little.The shape joins the object. The outline now goes around both.

    Cut a part or a hole

    1. Select the object.
    2. In the panel, click Erase.
    3. Press P or F and draw around the part to remove.The part disappears from the object. A shape inside the object leaves a hole.
    4. Click Fill to go back to adding.
    Good to know

    Save sets the switch back to Fill, so the next object starts in Fill.

    Holes are kept in the draft and in the export: the saved mask is the filled parts minus the erased parts.

    New SAM points replace the previous SAM outline of the object. Pieces you added with Fill and cuts you made with Erase stay.

    The SLIC window has its own switch, Add to mask / Remove from mask, and the brush in Refine has Add / Eraser.

    08

    Correct an outline

    Select an object to correct it: click the grain on the image, or click its name in the panel. The panel shows the edit tools at the top.

    To add a missing part or cut a hole with a polygon or a freeform stroke, use Fill and Erase. The tools below work on the pixels of the mask.

    Refine with a brush

    Use Refine for pixel-level touch-ups along an edge.

    1. Select the object and click Refine.The Refinement window opens on the object.
    2. Choose Add or Eraser.
    3. Set the Brush size (5 to 100 px).
    4. Paint on the mask. Use the wheel to zoom and the middle button to pan.
    5. Click Apply to keep the changes, or Cancel.

    Move vertices with anchors

    1. Select the object and click Show anchors.The outline becomes a set of vertices you can drag.
    2. Drag a vertex to move the edge.
    3. To delete a whole piece of the object, click its red × handle.
    4. Click Show anchors again to merge the vertices back into one mask.
    Anchors simplify the outline

    To make the vertices editable, the app simplifies the outline. Very fine details along the edge can be lost, and that loss is kept when you save. Use anchors on grains with simple shapes, and check the edge before you save.

    Delete an object

    Select the object, then click the red trash button next to its name, or press Delete. When you are not drawing, Backspace also deletes the selected object. Press Ctrl+Z to get it back.

    09

    Describe the mineral

    Each object records your identification as three ranked hypotheses, plus the optical properties you observed. A ranked list keeps the uncertainty that a single label would hide.

    1. Choose the 1st hypothesis — most probable.The object takes the name of this mineral. You can still edit the name in the field at the top.
    2. Choose the 2nd hypothesis.
    3. Choose the 3rd hypothesis — least probable.Save becomes available. All three hypotheses are required.
    4. Fill in the optical properties you observed. They are optional.
    5. Click Save.The panel returns to the object list, for example Augite — Augite › Hypersthene › Hornblende.
    Save is not a file save

    Save in the form closes the object and merges its pieces into one shape. It does not write anything to disk. To keep your work, use Save draft or Export annotation (current image). See Save and export.

    Save and export

    Three actions keep your work at three levels. The two file buttons sit at the bottom of the panel when no object is selected.

    ActionWritesUse it to
    Save (in the form)Nothing on diskFinish one object.
    Save draft<username>_task.json next to the imagesStop and resume later. The draft keeps every piece of every object, ready to edit.
    Export annotation (current image)<image>_annotator-<username>.thinannotation next to the imageDeliver the final result for the image on screen.
    • The export covers the image on screen only. To export another lighting variant, switch to it and click Export annotation (current image) again.
    • In a batch, Next exports every lighting variant of the task for you.
    • The browser also keeps a copy as you work. If the browser closes, the app offers to restore it (see Come back to a task). This copy is a safety net, not a replacement for Save draft.

    Leave a task

    Click Finish in the top-right corner. The Finish task dialog asks Do you want to save your changes before leaving?

    • Save and leave saves the draft, then returns to the home screen.
    • Leave without saving returns without saving.

    Open a new task in the top-left corner also leaves the task.

    If you step away

    Some installations close an idle task. After 4 minutes without activity (8 minutes while an object is open), the app plays a sound, flashes the browser tab title and asks Still there?. The sound and the flashing tab help when you are looking into the microscope.

    1. Click I am still here within 2 minutes.The dialog closes and you continue where you were.

    If nobody answers, the app saves the draft and returns to the home screen. If that save fails, the task stays open and the app shows Save failed — the task stays open.

    What the export contains

    The .thinannotation file is JSON in a COCO-like layout. Each grain stores its mask as RLE (run-length encoding) and the mineral data you entered. The file also records the lighting conditions of the image and your annotator profile.

    "metadata": { "lightning_modality": "PPL", "gamma": "na", "rotation": 45 },
"image": { "file_name": "GDX-22-PI_mod-PPL_comp-na_rot-45.bmp", "width": 2448, "height": 2048 },
"annotations": [{
    "segmentation": { "counts": "dS]d11fo1a0C7@?K5I7L4M2M…", "size": [2048, 2448] },
    "mineralIds": ["aug", "hyp", "hbl"],   // 1st, 2nd, 3rd hypothesis
    "relief": "high", "birefringence": "medium", "cleavage": "good", …
}],
"annotator_profile": { "username": "demo", "level": "expert", … }

    Troubleshooting

    The first click on an image takes a long time

    The model prepares each image once, on the first SAM point or box. This often takes about ten seconds. The next clicks on the same image take about one second. The app keeps the preparation, so opening the image again later is faster.

    "No image in this folder. Please select a valid task folder."

    The selected folder has no image the app can read.

    • Check that you selected the FOV folder, not its parent.
    • Check the file names with the file name checker.
    • Check that the format is one of .jpg .jpeg .png .tif .tiff .bmp.
    "No folder inside that root matches the expected structure."

    The batch search found no folder with correctly named images. Check one image name with the file name checker, then check the batch layout.

    "The service is not answering" or "Please check your connection and retry"

    The local server is stopped. Open the Control Panel, click Start Server, wait until it runs, then reload the browser page.

    The Save button stays grey

    All three hypotheses are required. Choose a mineral in the 1st, 2nd and 3rd hypothesis lists.

    My click selects another grain instead of drawing

    When no object is selected, a click on an existing grain selects it. Start the new grain on an empty area, or use the box tool around it. When an object is selected, clicks always go to the tool.

    Ctrl+Z does nothing inside Refine or SLIC

    Those windows have their own undo while they are open. Use their undo arrows, or Ctrl+Z inside the window. After Apply, the whole session is one step in the main history.

    Where are my files?

    Next to your images, in the FOV folder: <username>_task.json for the draft and one <image>_annotator-<username>.thinannotation per exported image.

    Can several people annotate the same folder?

    Yes. Each username gets its own draft and export files, so annotators do not overwrite each other. Do not share a username between two people.
